# Apocalyptic Lists

### @explicitHints true

## Walk through the moments

Use the simulator's expand button. Move the panda with the arrows.

Ten moment pads run from top to bottom: allies act, then enemies. Icons show each move, power and target. Beside a moment, **A** selects it; **B** watches its action without changing your lists.

## Build the altar job

Each Recipe shows the needed native blocks and the complete example. Keep your earlier room events; add the new job beside them.

At a physical altar, **A** runs your current code. **B** explains the list operation. Selecting a moment does not change the setup's marked position.

Start with [Open R01](#recipe:https://github.com/mrbrackebusch-code/apocalyptic-lists/recipes/r01).

## Release time

After using the altar, press **A** at the top **Release time** crystal. Watch the outcome at the bottom. Finish the list task and win, then use **A** at **Exit**.

**A** at the hourglass changes animation speed, not walking speed.

Need the exact strategy for this setup? **B** in open space → **Altar help + room strategy** → **A**. **Left / Right** turns pages; **B** returns. The same menu offers **Retry this setup** and **Try another setup**.

## Resume your expedition

The editor saves your code. Completed rooms, unlocks, the last travelled room and animation speed are remembered for this same MakeCode project in this browser. Open your saved project to resume. A new tutorial or project has separate progress.

A code restart resets unfinished in-room list edits. Use your altar code again.
