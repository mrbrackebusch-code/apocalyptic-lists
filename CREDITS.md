# Apocalyptic Lists

Game design and tutorial: project owner and development collaborators.

Monster, object and terrain source artwork: Dungeon Crawl / Project Utumno, supplied by the owner from [Dungeon Crawl 32×32 tiles](https://opengameart.org/content/dungeon-crawl-32x32-tiles). Native palette conversion, teaching glyphs and numeric badges are game-owned adaptations.

Programming-teaching sources: Microsoft MakeCode Arcade CSIntro2 Arrays Intro, Arrays of Strings and Arrays of Sprites; Microsoft MakeCode AP CSP String Arrays. See copy/SOURCE_LINEAGE.md and SOURCE_NOTICES.md.
