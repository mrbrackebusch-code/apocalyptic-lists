## Left altar: delay the moves

First, delay the enemy script by one moment.

![Blocks and variable setup for Left altar in room 24](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R24-primary-menu.svg)

![Complete Left altar code for room 24, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R24-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R24, apocTypes.Station.Primary, function () {
    let enemyMoves: string[] = apocalypse.moves(apocTypes.Side.Enemy)
    enemyMoves.unshift("Wait")
    apocalypse.setMoves(apocTypes.Side.Enemy, enemyMoves)
})
```

## Right altar: cancel the shifted Attack

Then cancel the Attack at its shifted position.

![Blocks and variable setup for Right altar in room 24](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R24-secondary-menu.svg)

![Complete Right altar code for room 24, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R24-secondary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R24, apocTypes.Station.Secondary, function () {
    let shiftedMoves: string[] = apocalypse.moves(apocTypes.Side.Enemy)
    let markedIndex = apocalypse.markedIndex()
    if (markedIndex >= 0 && markedIndex < shiftedMoves.length) {
        shiftedMoves[markedIndex] = "Wait"
        apocalypse.setMoves(apocTypes.Side.Enemy, shiftedMoves)
    }
})
```

## Try your code

**A** at **Left altar**, then **A** at **Right altar**. Use that order. Then **A** at the top **Release time** crystal.

A new Wait is first; the old enemy moves shift later. The marked Attack in the shifted list becomes Wait.
