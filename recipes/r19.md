## Choose one enemy at random

Freeze one randomly chosen enemy.

![Blocks and variable setup for Left altar in room 19](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R19-primary-menu.svg)

![Complete Left altar code for room 19, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R19-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R19, apocTypes.Station.Primary, function () {
    let enemies: Sprite[] = apocalypse.roster()
    if (enemies.length > 0) {
        let randomIndex = randint(0, enemies.length - 1)
        let enemyToFreeze: Sprite = enemies[randomIndex]
        apocalypse.hold(enemyToFreeze)
    }
})
```

## Try your code

**A** at **Left altar**, then **A** at the top **Release time** crystal.
