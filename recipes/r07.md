## Remove one shield

Keep your earlier room code. Add ``||apocalypse(noclick):on room R07 station Primary||`` from ``||apocalypse(noclick):Apocalyptic Lists||``. Put this room's work inside that event. Use ``||variables(noclick):Make a Variable||`` for any new names in this construction: `enemyMoves`, `marked`. Reuse a name that already exists in your project.

The marked enemy `Ward` is gone. The enemy move list is shorter by one, with later items shifted left.

apocalypse.onInteract(apocTypes.Room.R07, apocTypes.Station.Primary, function () {
    let enemyMoves: string[] = apocalypse.moves(apocTypes.Side.Enemy)
    let marked = apocalypse.markedIndex()
    if (marked >= 0 && marked < enemyMoves.length) {
        enemyMoves.removeAt(marked)
        apocalypse.setMoves(apocTypes.Side.Enemy, enemyMoves)
    }
})
