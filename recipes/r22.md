## Move a target to the front

Put the marked enemy portrait first so our opening attack aims there.

![Blocks and variable setup for Left altar in room 22](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R22-primary-menu.svg)

![Complete Left altar code for room 22, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R22-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R22, apocTypes.Station.Primary, function () {
    let enemyTargets: Sprite[] = apocalypse.targets(apocTypes.Side.Enemy)
    let markedIndex = apocalypse.markedIndex()
    if (markedIndex >= 0 && markedIndex < enemyTargets.length) {
        let movedTarget: Sprite = enemyTargets.removeAt(markedIndex)
        enemyTargets.unshift(movedTarget)
        apocalypse.setTargets(apocTypes.Side.Enemy, enemyTargets)
    }
})
```
