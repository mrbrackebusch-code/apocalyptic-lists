## Freeze every enemy

Freeze every enemy in the enemy list.

![Blocks and variable setup for Left altar in room 13](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R13-primary-menu.svg)

![Complete Left altar code for room 13, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R13-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R13, apocTypes.Station.Primary, function () {
    let enemies: Sprite[] = apocalypse.roster()
    for (let enemy of enemies) {
        apocalypse.hold(enemy)
    }
})
```

## Try your code

**A** at **Left altar**, then **A** at the top **Release time** crystal.

Every enemy is frozen; no enemy entry is removed.

![Actual altar interaction, list change, battle and outcome in room 13](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/demos/v0.6.0/r13.gif)
