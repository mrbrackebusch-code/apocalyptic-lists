## Match two lists by index

Put a Shield only in a defense gap opposite an Attack.

![Blocks and variable setup for Left altar in room 25](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R25-primary-menu.svg)

![Complete Left altar code for room 25, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R25-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R25, apocTypes.Station.Primary, function () {
    let ourMoves: string[] = apocalypse.moves(apocTypes.Side.Ally)
    let enemyMoves: string[] = apocalypse.moves(apocTypes.Side.Enemy)
    for (let index = 0; index <= ourMoves.length - 1; index++) {
        if (ourMoves[index] == "Wait" && enemyMoves[index] == "Attack") {
            ourMoves[index] = "Shield"
        }
    }
    apocalypse.setMoves(apocTypes.Side.Ally, ourMoves)
})
```
