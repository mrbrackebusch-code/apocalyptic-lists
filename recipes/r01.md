## Build your first move list

Build the script that protects Medic, then finishes the enemies.

Expand the simulator. Move with arrows; **A** uses nearby room objects.

![Blocks and variable setup for Left altar in room 1](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R01-primary-menu.svg)

![Complete Left altar code for room 1, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R01-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R01, apocTypes.Station.Primary, function () {
    let ourMoves: string[] = []
    ourMoves = []
    for (let index = 0; index <= apocalypse.numberHint() - 1; index++) {
        ourMoves.push("Wait")
    }
    ourMoves.push("Shield")
    ourMoves.push("Heal")
    ourMoves.push("Attack")
    ourMoves.push("Attack")
    apocalypse.setMoves(apocTypes.Side.Ally, ourMoves)
})
```

## Try your code

**A** at **Left altar**, then **A** at the top **Release time** crystal.

The shown Waits come first, then Shield, Heal, Attack, Attack.

![Actual altar interaction, list change, battle and outcome in room 1](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/demos/v0.6.0/r01.gif)
