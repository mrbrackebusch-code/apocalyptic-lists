## Roll a stronger first power

The first and fourth powers start at 1. Roll only the first power to make a stronger donor.

![Blocks and variable setup for Right altar in room 14](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R14-secondary-menu.svg)

![Complete Right altar code for room 14, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R14-secondary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R14, apocTypes.Station.Secondary, function () {
    let rolledPowers: number[] = apocalypse.values(apocTypes.Side.Ally)
    rolledPowers[0] = randint(4, 9)
    apocalypse.setValues(apocTypes.Side.Ally, rolledPowers)
})
```

## Swap first and fourth

Move the strong first power to Boss's fourth-moment Attack. Use savedPower to keep the first power before replacing it.

![Blocks and variable setup for Left altar in room 14](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R14-primary-menu.svg)

![Complete Left altar code for room 14, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R14-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R14, apocTypes.Station.Primary, function () {
    let ourPowers: number[] = apocalypse.values(apocTypes.Side.Ally)
    let savedPower = ourPowers[0]
    ourPowers[0] = ourPowers[3]
    ourPowers[3] = savedPower
    apocalypse.setValues(apocTypes.Side.Ally, ourPowers)
})
```

## Try your code

**A** at **Right altar**, then **A** at **Left altar**, then **A** at the top **Release time** crystal.

Roll first until it meets this setup's minimum in **Altar help + room strategy**, then swap. The strong number ends fourth; 1 ends first. Rolling alone or swapping the starting 1s cannot win.

![Actual altar interaction, list change, battle and outcome in room 14](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/demos/v0.6.0/r14.gif)



After success, use **A** at the bottom **Exit**, then [Open room 15](#recipe:https://github.com/mrbrackebusch-code/apocalyptic-lists/recipes/r15).
