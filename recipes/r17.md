## Transfer a reserve move

Use the last move waiting in reserve.

![Blocks and variable setup for Left altar in room 17](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R17-primary-menu.svg)

![Complete Left altar code for room 17, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R17-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R17, apocTypes.Station.Primary, function () {
    let reserveMoves: string[] = apocalypse.sourceMoves()
    let ourMoves: string[] = apocalypse.moves(apocTypes.Side.Ally)
    if (reserveMoves.length > 0) {
        let reserveMove: string = reserveMoves.pop()
        apocalypse.setSourceMoves(reserveMoves)
        ourMoves.push(reserveMove)
        apocalypse.setMoves(apocTypes.Side.Ally, ourMoves)
    }
})
```

## Try your code

**A** at **Left altar**, then **A** at the top **Release time** crystal.

The reserve loses its last move; that same move ends the our list.
