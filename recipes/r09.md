## Remove the first move

Remove the opening Wait so the protection comes sooner.

![Blocks and variable setup for Left altar in room 9](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R09-primary-menu.svg)

![Complete Left altar code for room 9, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R09-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R09, apocTypes.Station.Primary, function () {
    let ourMoves: string[] = apocalypse.moves(apocTypes.Side.Ally)
    ourMoves.shift()
    apocalypse.setMoves(apocTypes.Side.Ally, ourMoves)
})
```

## Try your code

**A** at **Left altar**, then **A** at the top **Release time** crystal.

The first move disappears; the remaining moves move earlier.

![Actual altar interaction, list change, battle and outcome in room 9](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/demos/v0.6.0/r09.gif)
