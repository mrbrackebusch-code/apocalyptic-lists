## Remove the final move

Delete the enemy's final attack.

![Blocks and variable setup for Left altar in room 10](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R10-primary-menu.svg)

![Complete Left altar code for room 10, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R10-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R10, apocTypes.Station.Primary, function () {
    let enemyMoves: string[] = apocalypse.moves(apocTypes.Side.Enemy)
    enemyMoves.pop()
    apocalypse.setMoves(apocTypes.Side.Enemy, enemyMoves)
})
```

## Try your code

**A** at **Left altar**, then **A** at the top **Release time** crystal.

The last enemy move is gone; earlier moves stay put.

![Actual altar interaction, list change, battle and outcome in room 10](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/demos/v0.6.0/r10.gif)
