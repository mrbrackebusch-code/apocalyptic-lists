## Delay the enemy

Delay the enemy script until the shield is ready.

![Blocks and variable setup for Left altar in room 6](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R06-primary-menu.svg)

![Complete Left altar code for room 6, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R06-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R06, apocTypes.Station.Primary, function () {
    let enemyMoves: string[] = apocalypse.moves(apocTypes.Side.Enemy)
    enemyMoves.unshift("Wait")
    apocalypse.setMoves(apocTypes.Side.Enemy, enemyMoves)
})
```

## Try your code

**A** at **Left altar**, then **A** at the top **Release time** crystal.

Wait becomes first; every old enemy move moves one place later.

![Actual altar interaction, list change, battle and outcome in room 6](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/demos/v0.6.0/r06.gif)
