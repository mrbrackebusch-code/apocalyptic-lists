## Find the final entry

Repair the last our move, however long the list is.

![Blocks and variable setup for Left altar in room 8](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R08-primary-menu.svg)

![Complete Left altar code for room 8, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R08-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R08, apocTypes.Station.Primary, function () {
    let ourMoves: string[] = apocalypse.moves(apocTypes.Side.Ally)
    if (ourMoves.length > 0) {
        ourMoves[ourMoves.length - 1] = "Attack"
        apocalypse.setMoves(apocTypes.Side.Ally, ourMoves)
    }
})
```

## Try your code

**A** at **Left altar**, then **A** at the top **Release time** crystal.

Only the last our move becomes Attack.

![Actual altar interaction, list change, battle and outcome in room 8](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/demos/v0.6.0/r08.gif)
