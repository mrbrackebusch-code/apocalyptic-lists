## Insert at the matching index

Place Shield opposite the first enemy Attack.

![Blocks and variable setup for Left altar in room 21](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R21-primary-menu.svg)

![Complete Left altar code for room 21, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R21-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R21, apocTypes.Station.Primary, function () {
    let enemyMoves: string[] = apocalypse.moves(apocTypes.Side.Enemy)
    let ourMoves: string[] = apocalypse.moves(apocTypes.Side.Ally)
    let attackIndex = enemyMoves.indexOf("Attack")
    if (attackIndex >= 0 && attackIndex <= ourMoves.length) {
        ourMoves.insertAt(attackIndex, "Shield")
        apocalypse.setMoves(apocTypes.Side.Ally, ourMoves)
    }
})
```
