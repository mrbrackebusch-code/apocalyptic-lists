## Take an enemy out of play

Banish the first enemy from the battle.

![Blocks and variable setup for Left altar in room 11](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R11-primary-menu.svg)

![Complete Left altar code for room 11, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R11-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R11, apocTypes.Station.Primary, function () {
    let enemies: Sprite[] = apocalypse.roster()
    if (enemies.length > 0) {
        let removedEnemy: Sprite = enemies.shift()
        apocalypse.setRoster(enemies)
        apocalypse.banish(removedEnemy)
    }
})
```

## Try your code

**A** at **Left altar**, then **A** at the top **Release time** crystal.

The enemy list loses its first entry, and that same enemy is banished.
