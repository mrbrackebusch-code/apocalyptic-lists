## Insert a shield

Put a Shield before the incoming hit.

![Blocks and variable setup for Left altar in room 5](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R05-primary-menu.svg)

![Complete Left altar code for room 5, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R05-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R05, apocTypes.Station.Primary, function () {
    let ourMoves: string[] = apocalypse.moves(apocTypes.Side.Ally)
    ourMoves.insertAt(apocalypse.markedIndex(), "Shield")
    apocalypse.setMoves(apocTypes.Side.Ally, ourMoves)
})
```

## Try your code

**A** at **Left altar**, then **A** at the top **Release time** crystal.

Shield is inserted; later our moves shift toward later moments.
