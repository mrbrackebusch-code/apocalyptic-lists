## Remember what happened earlier

Build Shields, Heal once after an Attack, and Attack in other openings.

![Blocks and variable setup for Left altar in room 26](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R26-primary-menu.svg)

![Complete Left altar code for room 26, with explanations beside the relevant blocks](https://raw.githubusercontent.com/mrbrackebusch-code/apocalyptic-lists/main/assets/instructions/v0.6.0/R26-primary-assembled.svg)

#### ~ tutorialhint

```blocks
apocalypse.onInteract(apocTypes.Room.R26, apocTypes.Station.Primary, function () {
    let reserveMoves: string[] = apocalypse.sourceMoves()
    let ourMoves: string[] = []
    ourMoves = []
    let seenAttack = false
    let didHeal = false
    seenAttack = false
    didHeal = false
    for (let move of reserveMoves) {
        if (move == "Attack") {
            seenAttack = true
            ourMoves.push("Shield")
        } else if (seenAttack && !didHeal) {
            ourMoves.push("Heal")
            didHeal = true
        } else {
            ourMoves.push("Attack")
        }
    }
    apocalypse.setMoves(apocTypes.Side.Ally, ourMoves)
})
```

## Try your code

**A** at **Left altar**, then **A** at the top **Release time** crystal.

Shield answers every Attack. Heal fills the first later Wait; other Waits get Attack.
