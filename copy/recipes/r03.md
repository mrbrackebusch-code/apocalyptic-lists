## Change one move

Keep your earlier room code. Add ``||apocalypse(noclick):on room R03 station Primary||`` from ``||apocalypse(noclick):Apocalyptic Lists||``. Put this room's work inside that event. Now change a value in an existing list. Set `enemyMoves` to ``||apocalypse(noclick):Enemy move list||`` and `marked` to ``||apocalypse(noclick):marked index||``.

<!-- AP_MEDIA id=R03-blocks -->

Use ``||arrays(noclick):set value at||`` to put `Wait` at that index, then ``||apocalypse(noclick):use enemyMoves as Enemy move list||``. The existing cell changes; the list keeps the same number of entries. The room gives you a copy to work on, so the final **use** block submits your edited list.

Use ``||variables(noclick):Make a Variable||`` for any new names in this construction: `enemyMoves`, `marked`. Reuse a name that already exists in your project.

**Try your code.** Walk to **Rewrite** (the Primary station) and press **A** once. Watch the highlighted cells and the actors, then press **B**, choose **Run the plan**, and press **A**.

The marked enemy `Strike` becomes `Wait`. No item is inserted or removed.

<!-- AP_MEDIA id=R03-before-after -->

If the result differs, choose **Retry this setup** from the B menu, revise your code, and try the station again. After a code edit or restart the room returns to its starting lists; run your current station code again.

After success, use the **Exit** gate to enter the next room, then follow {{recipe:R04}}. This link keeps your current project.
