## Remember what happened earlier

Keep your earlier room code. Add ``||apocalypse(noclick):on room R26 station Primary||`` from ``||apocalypse(noclick):Apocalyptic Lists||``. Put this room's work inside that event. Build a new allied move list from `sourceMoves`. Append `Ward` for each `Strike`. At the first opening **after an attack**, append one `Mend`; append `Strike` at the other openings.

Use `seenAttack` and `didHeal` to remember what has happened earlier in the traversal. Reset both to false when this station event begins. Each source cell must produce exactly one output.

Use ``||variables(noclick):Make a Variable||`` for any new names in this construction: `sourceMoves`, `allyMoves`, `seenAttack`, `didHeal`. Reuse a name that already exists in your project.

<!-- AP_MEDIA id=R26-blocks -->

**Try your code.** Walk to **Build recovery** (the Primary station) and press **A** once. Watch the highlighted cells and the actors, then press **B**, choose **Run the plan**, and press **A**.

There is one output for each source move: `Ward` against an attack, one `Mend` at the first later opening, and `Strike` at other openings.

<!-- AP_MEDIA id=R26-before-after -->

If the result differs, choose **Retry this setup** from the B menu, revise your code, and try the station again. After a code edit or restart the room returns to its starting lists; run your current station code again.

After success, use the **Exit** gate to enter the next room, then follow {{recipe:R27}}. This link keeps your current project.
