## Swap two numbers

Keep your earlier room code. Add ``||apocalypse(noclick):on room R14 station Primary||`` from ``||apocalypse(noclick):Apocalyptic Lists||``. Put this room's work inside that event. Read `allyValues`. Make `savedNumber` to remember the original value at index **0**. Move the value from index **3** into cell 0, then put `savedNumber` into cell 3. Submit the value list.

The temporary variable keeps the first value available while its old cell changes. Predict what would be lost if both assignments read from the already changed list.

Use ``||variables(noclick):Make a Variable||`` for any new names in this construction: `allyValues`, `savedNumber`. Reuse a name that already exists in your project.

<!-- AP_MEDIA id=R14-blocks -->

**Try your code.** Walk to **Swap power** (the Primary station) and press **A** once. Watch the highlighted cells and the actors, then press **B**, choose **Run the plan**, and press **A**.

The numbers from allied positions 0 and 3 exchange places; positions 1 and 2 stay untouched.
