## Swap two numbers

Keep your earlier room code. Add ``||apocalypse(noclick):on room R14 station Primary||`` from ``||apocalypse(noclick):Apocalyptic Lists||``. Put this room's work inside that event. Read `allyValues`. Make `savedNumber` to remember the first power (code index **0**). Put the fourth power (code index **3**) in the first place, then put `savedNumber` in the fourth place. Submit the value list.

The temporary variable keeps the first value available while its old entry changes. Predict what would be lost if both assignments read from the already changed list.

Use ``||variables(noclick):Make a Variable||`` for any new names in this construction: `allyValues`, `savedNumber`. Reuse a name that already exists in your project.
