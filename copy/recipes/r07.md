## Remove one shield

Keep your earlier room code. Add ``||apocalypse(noclick):on room R07 station Primary||`` from ``||apocalypse(noclick):Apocalyptic Lists||``. Put this room's work inside that event. Read `enemyMoves` and the `marked` index. Use ``||arrays(noclick):remove value at||`` to remove the marked move, then submit the shorter enemy move list.

<!-- AP_MEDIA id=R07-blocks -->

Removing a cell shifts later entries left. This block can also return the removed value; here the room needs only the deletion, so you do not have to keep that value.

Use ``||variables(noclick):Make a Variable||`` for any new names in this construction: `enemyMoves`, `marked`. Reuse a name that already exists in your project.

**Try your code.** Walk to **Remove Ward** (the Primary station) and press **A** once. Watch the highlighted cells and the actors, then press **B**, choose **Run the plan**, and press **A**.

The marked enemy `Ward` is gone. The enemy move list is shorter by one, with later items shifted left.

<!-- AP_MEDIA id=R07-before-after -->

If the result differs, choose **Retry this setup** from the B menu, revise your code, and try the station again. After a code edit or restart the room returns to its starting lists; run your current station code again.

After success, use the **Exit** gate to enter the next room, then follow {{recipe:R08}}. This link keeps your current project.
