## Move the same target

Keep your earlier room code. Add ``||apocalypse(noclick):on room R22 station Primary||`` from ``||apocalypse(noclick):Apocalyptic Lists||``. Put this room's work inside that event. Remove the marked Sprite from `enemyTargets`, remembering the returned reference. Insert that same Sprite at the beginning of the target list, then submit it.

The target count stays the same: one removal and one insertion move an existing reference.

Use ``||variables(noclick):Make a Variable||`` for any new names in this construction: `enemyTargets`, `marked`, `selected`. Reuse a name that already exists in your project.
