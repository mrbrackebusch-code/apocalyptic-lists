## Find a move by its value

Keep your earlier room code. Add ``||apocalypse(noclick):on room R12 station Primary||`` from ``||apocalypse(noclick):Apocalyptic Lists||``. Put this room's work inside that event. The `Ward` is in a different position in each attempt. Read `enemyMoves` and use ``||arrays(noclick):index of||`` to search for `Ward`. Store the answer in `found`.

A search returns **−1** when it finds no match. If `found ≥ 0`, set the value at `found` to `Wait`, then submit the move list.

Use ``||variables(noclick):Make a Variable||`` for any new names in this construction: `enemyMoves`, `found`. Reuse a name that already exists in your project.

<!-- AP_MEDIA id=R12-blocks -->

**Try your code.** Walk to **Find Ward** (the Primary station) and press **A** once. Watch the highlighted cells and the actors, then press **B**, choose **Run the plan**, and press **A**.

The current enemy `Ward` changes to `Wait` wherever the search finds it. Other entries remain unchanged.
