## Find a move by its value

Keep your earlier room code. Add ``||apocalypse(noclick):on room R12 station Primary||`` from ``||apocalypse(noclick):Apocalyptic Lists||``. Put this room's work inside that event. The `Ward` can be in a different position in each setup. Read `enemyMoves` and use ``||arrays(noclick):index of||`` to search for `Ward`. Store the answer in `found`.

A search returns **−1** when it finds no match. If `found ≥ 0`, set the value at `found` to `Wait`, then submit the move list.

Use ``||variables(noclick):Make a Variable||`` for any new names in this construction: `enemyMoves`, `found`. Reuse a name that already exists in your project.

<!-- AP_MEDIA id=R12-blocks -->

**Try your code.** Walk the panda to **Find Ward** (the Primary altar) and press **A** once. Watch the altar's changes to the pieces and actors. Then walk to the **Release time** crystal at the top and press **A**. Watch the battle and the outcome at the bottom.

The current enemy `Ward` changes to `Wait` wherever the search finds it. Other entries remain unchanged.
