## Find the final cell

Keep your earlier room code. Add ``||apocalypse(noclick):on room R08 station Primary||`` from ``||apocalypse(noclick):Apocalyptic Lists||``. Put this room's work inside that event. Read `allyMoves`. Make a variable `last` to store ``||arrays(noclick):length of array||`` **− 1**. Put that index into ``||arrays(noclick):set value at||`` and change the final move to `Strike`, then submit the list.

<!-- AP_MEDIA id=R08-blocks -->

The length counts all cells; the final index is one less because counting starts at 0. Use that calculation so the same code works when an attempt has a longer list.

Use ``||variables(noclick):Make a Variable||`` for any new names in this construction: `allyMoves`. Reuse a name that already exists in your project.

**Try your code.** Walk to **Repair last** (the Primary station) and press **A** once. Watch the highlighted cells and the actors, then press **B**, choose **Run the plan**, and press **A**.

Only the last allied `Wait` changes to `Strike`; list length does not change, even in a longer setup.

<!-- AP_MEDIA id=R08-before-after -->

If the result differs, choose **Retry this setup** from the B menu, revise your code, and try the station again. After a code edit or restart the room returns to its starting lists; run your current station code again.

After success, use the **Exit** gate to enter the next room, then follow {{recipe:R09}}. This link keeps your current project.
