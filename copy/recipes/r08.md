## Find the final entry

Keep your earlier room code. Add ``||apocalypse(noclick):on room R08 station Primary||`` from ``||apocalypse(noclick):Apocalyptic Lists||``. Put this room's work inside that event. Read `allyMoves`. Use ``||arrays(noclick):length of array||`` **− 1** as the index in ``||arrays(noclick):set value at||`` and change the final move to `Strike`, then submit the list.

<!-- AP_MEDIA id=R08-blocks -->

The length counts all entries; the final index is one less because counting starts at 0. Use that calculation so the same code works when an attempt has a longer list.

Use ``||variables(noclick):Make a Variable||`` for any new names in this construction: `allyMoves`. Reuse a name that already exists in your project.

**Try your code.** Walk the panda to **Repair last** (the Primary altar) and press **A** once. Watch the altar's changes to the pieces and actors. Then walk to the **Release time** crystal at the top and press **A**. Watch the battle and the outcome at the bottom.

Only the last allied `Wait` changes to `Strike`; list length does not change, even in a longer setup.

<!-- AP_MEDIA id=R08-before-after -->

If the result differs, use **B** in open space and choose **Retry this setup**, revise your code, and use the altar again. After a code edit or restart, the room returns to its starting lists; run your current altar code again.
