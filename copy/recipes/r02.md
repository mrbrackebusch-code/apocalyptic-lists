## Hold one hazard

Keep your earlier room code. Add ``||apocalypse(noclick):on room R02 station Primary||`` from ``||apocalypse(noclick):Apocalyptic Lists||``. Put this room's work inside that event. The hazard roster is a list of the actual characters in this room. An entry refers to a Sprite, rather than its written name.

<!-- AP_MEDIA id=R02-blocks -->

Make variables `hazardRoster`, `marked` and `selected`. Set `hazardRoster` to ``||apocalypse(noclick):hazard roster||`` and `marked` to ``||apocalypse(noclick):marked index||``. Use ``||arrays(noclick):get value at||`` with that roster and index; store the returned Sprite in `selected`, then put `selected` into ``||apocalypse(noclick):hold selected||``.

Array indices begin at **0**, so index 0 names the first entry. The comparison in the example checks that the marker is inside the list. Holding changes that actor's state; it leaves the roster's entries in place.

Use ``||variables(noclick):Make a Variable||`` for any new names in this construction: `hazardRoster`, `marked`, `selected`. Reuse a name that already exists in your project.

The marked position comes from this setup. Selecting a moment with **A** does not change that marker.

**Try your code.** Walk the panda to **Hold threat** (the Primary altar) and press **A** once. Watch the altar's changes to the pieces and actors. Then walk to the **Release time** crystal at the top and press **A**. Watch the battle and the outcome at the bottom.

Only the marked real hazard is held. The roster still contains the same Sprite references in the same order.

<!-- AP_MEDIA id=R02-before-after -->

If the result differs, use **B** in open space and choose **Retry this setup**, revise your code, and use the altar again. After a code edit or restart, the room returns to its starting lists; run your current altar code again.

**Need a reminder?** Press **B** beside the altar for its list-operation explanation. For the exact strategy for this setup, press **B** in open space, choose **Altar help + room strategy** with **A**, and use **Left / Right** to turn pages. Beside a moment pad, **A** selects its action and **B** watches it. Use **A** at the hourglass before releasing time to change animation speed.

After success, walk to the bottom **Exit** gate and press **A** to enter the next room, then follow {{recipe:R03}}. This link keeps your current project.
