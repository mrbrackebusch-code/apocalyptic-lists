## Build a response list

Keep your earlier room code. Add ``||apocalypse(noclick):on room R16 station Primary||`` from ``||apocalypse(noclick):Apocalyptic Lists||``. Put this room's work inside that event. Use `sourceMoves` as the read-only script. Build a new, empty `allyMoves` list. For each source move, append `Ward` for `Strike`, or `Strike` for `Wait`. Submit the new list when the loop finishes.

Keep the source order: each input produces one output.

Use ``||variables(noclick):Make a Variable||`` for any new names in this construction: `sourceMoves`, `allyMoves`. Reuse a name that already exists in your project.

Each source move produces one allied move in the same order: `Strike` → `Ward`, and `Wait` → `Strike`. The source list stays unchanged.
