# Game art credits

**Panda:** Panda Character 32x32 by **danielmahon —
[@danielmahon](https://twitter.com/danielmahon)**.
[Source page](https://opengameart.org/content/panda-character-32x32) ·
[CC-BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
Game preparations crop frames, map them to the existing Arcade palette and mirror
the supplied right-facing poses for left-facing movement. Original source and
[full panda credit](assets/panda/CREDITS.md) are preserved.

**Allied heroes:** RPG sprite set 1 by **Antifarea**, enlarged transparent fixed
version submitted by **Maxion**, on **[OpenGameArt.org](https://opengameart.org/)**.
[Source page](https://opengameart.org/content/antifareas-rpg-sprite-set-1-enlarged-w-transparent-background-fixed) ·
[CC-BY 3.0](https://creativecommons.org/licenses/by/3.0/).
Game preparations crop existing frames and map them to the shared palette.
[Full hero credit](assets/antifarea-heroes/CREDITS.md) and original ZIP/PNGs
are preserved.

**Monsters and physical props:** owner-supplied Dungeon Crawl Stone Soup /
Project Utumno collection. The authoring catalog and selected asset
manifest retain exact archive paths. The time crystal combines the supplied
crystal ball with the supplied stone plinth; altars, fountain and exit use
supplied environment sprites.

For an in-game credits panel, native data is available through
`apocArt.creditCount()` and `apocArt.creditLine(index)`. Its four lines name
@danielmahon, the panda source URL, Antifarea, OpenGameArt.org and Maxion with the
specified license identifiers. Display wiring belongs to the game view.
